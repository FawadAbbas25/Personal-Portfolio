# Fawad Abbas — 3D Developer Portfolio

A responsive portfolio inspired by the visual language of the supplied Bianca reference: dark editorial layout, vivid green accent, rounded panels, large typography, project cards, and 3D motion.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Poppins + Syne

## Features
- Responsive navigation
- Smooth scrolling
- Scroll reveal animation
- Mouse-follow 3D tilt cards
- Floating/glowing visual effects
- Responsive project, service and skill sections
- Mobile navigation

## Customize
Replace these placeholders in `index.html`:
- `your.email@example.com`
- GitHub URL
- LinkedIn URL

Project GitHub links are also placeholders.
